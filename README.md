# PS-2025-CARTECIEL

*PS = Projet Scolaire*

## 📚 Projet Scolaire | Carte du ciel

Janvier - Mars 2025

Groupe : Yasmine, Colas, Théo et Juliette

### 📌 Consignes du projet :

A partir d’une base de données disponible comportant à minima 3000 objets célestes, l’objectif est de construire une application pour développer une carte du ciel représentant ces objets. Cette carte sera affichable dans une page « Web ». Cette carte devra comporter un ou des menus afin de :

● Visualiser à minima, les 50 étoiles les plus proche de la terre, visibles à l’oeil nu.

● Visualiser à minima, les 50 étoiles les plus brillantes.

● Visualiser à minima, les 50 étoiles les plus chaudes.

● Visualiser à minima, les 50 étoiles les plus grosses.

● Visualiser les constellations auxquelles appartiennent ces étoiles.

● Visualiser les planètes du système solaire.

● La souris passant sur une étoile devra ouvrir un « pop-up » mentionnant le nom de l’objet, ainsi que le nom la constellation, éventuelle, à laquelle il appartient. Les autres étoiles de la constellation seront aussi visualisées.

Cette carte du ciel aura pour point d’observation n’importe quel point du globe terrestre ainsi que n’importe quelle date du temps nous régissant. Le lieu, l’heure et la date d’observation seront paramétrables dans l’application. Un programme exécutable ou un lien d’exécution ainsi qu’un tutoriel seront fournis. Les hypothèses de travail sont à répertorier. Le travail demandé est le suivant : 

1er - Créer les « User Stories » du projet : Cela va déterminer tous les éléments de travail du projet.

2ème – Déterminer le « Product Backlog » du projet : A partir des US précédemment créées, déterminer le Product Backlog du projet. Ce dernier comprendra bien sûr les fonctionnalités (User Stories) demandées, et aussi d’autres éléments logiciels nécessaires pour réaliser le produit demandé.

3ème – Définir une première itération (sprint backlog) Valider le contenu de cette première itération avec l’animateur.

5ème – Réaliser l’implémentation de la 1ère itération

Faire une démo en fin du « workshop #5 », et délivrer une documentation « Projet » incluant les éléments de conduite « Agile » ciblés et suivis :
Eléments de conduite « Agile » Scrum et Kanban Product backlog, Scrum Roles, Sprint backlog, DoR, DoD, User Stories with points, Sprint Velocity,
Burdown Chart, Sprint Review, Sprint Retrospective, Kanban board
